### 바닥청소(구역별 원터치)
`바닥청소` 카드 안에 구역 4곳(`스크린쪽 바닥`, `타석쪽 바닥`, `대기실`, `광장`) × **청소기 / 물걸레질** 버튼이 그대로 나옵니다.
세부내역 시트를 열지 않고 **한 번 누르면 바로 DB에 기록**되고, 다시 누르면 해제됩니다.
누른 칸에는 누가 · 몇 시에 했는지(예: `이재근 · 21:34`)가 함께 남고, 다른 사람 폰에도 실시간으로 반영됩니다.
카드 위 `+ 청소기 전체` / `+ 물걸레질 전체`는 아직 안 된 구역만 한 번에 채웁니다(다른 사람 기록은 지우지 않음).
오늘 `4/4 구역`이 채워지면 항목이 완료로 바뀌고, 상단 `오늘 할 일`의 바닥청소 칩에는 `청소기 4/4 · 물걸레질 1/4`
진행률이 보입니다(칩을 누르면 해당 카드로 스크롤).
`options_json`에 `zones`·`methods`가 있는 항목은 설정에서 새로 추가해도 같은 인라인 버튼 UI로 표시됩니다.
기록은 `cleaning_logs`에 구역·방식 단위 행으로 남고(최근 이력에서는 같은 날 기록을 한 줄로 묶어 표시),
`이력` 버튼에서 누가·언제 했는지 그대로 확인할 수 있습니다.
짧은 메모는 카드의 `메모` 버튼으로 오늘 기록에 붙여 남깁니다.

## DB 테이블 (기존 `students`·`lessons`·`settings`는 건드리지 않음)

- `cleaning_items` — `id`, `title`, `category`(매일/2개월/4개월/6개월), `interval_days`(1/60/120/180),
  `options_json`(구역·방식 등), `sort_order`, `active`, `created_at`
- `cleaning_logs` — `id`, `item_id`(→ cleaning_items, 삭제 시 함께 삭제), `staff_name`, `detail`(jsonb), `memo`, `done_at`
- `cleaning_staff` — `id`, `name`, `role`(매니저/프로), `sort_order`

RLS: 세 테이블 모두 anon/authenticated 전체 허용(실험용), `supabase_realtime` publication 등록.
스키마·시드 원본: [`supabase-schema.sql`](supabase-schema.sql)

## 쓰는 법

1. 폰 브라우저에서 앱 주소를 열고 **홈 화면에 추가**(iOS: 공유 → 홈 화면에 추가)하면 앱처럼 뜹니다.
2. 맨 위에서 **지금 체크하는 사람**을 고릅니다(한 번 고르면 기억).
3. 항목의 **완료**를 누르면 즉시 기록되고, 다른 사람 폰에도 바로 반영됩니다.
   바닥청소는 카드 안 구역별 **청소기 / 물걸레질** 버튼을 바로 누릅니다(다시 누르면 해제).
4. 잘못 눌렀으면 뜨는 **실행취소**로 되돌립니다.
5. 새 항목·담당자는 오른쪽 위 **⚙ 설정**에서 바로 추가/수정/삭제합니다.
